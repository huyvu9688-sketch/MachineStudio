# Guided Cylinder Sizing 0.2.0 — Stage 1 Engineering Specification

## Scope

`guided-cylinder-sizing@0.2.0` is a future MGP-first selection workflow. It
uses SMC MGP selection graphs for a `vertical_lifter`, `horizontal_pusher`, or
`stopper`. The released `guided-cylinder-sizing@0.1.0` package remains
immutable.

## Engineering inputs

The workflow reuses these existing parameter IDs unchanged:

- `motion.axis.total_moving_mass`
- `pneumatic_guided_sizing.required_stroke`
- `pneumatic.operating_pressure`
- `pneumatic.max_piston_speed`

It adds exactly these MGP-specific IDs:

- `pneumatic_guided_mgp_sizing.application_case`
- `pneumatic_guided_mgp_sizing.eccentric_distance`
- `pneumatic_guided_mgp_sizing.load_safety_factor`
- `pneumatic_guided_mgp_sizing.transfer_speed`

The application case selects the MGP graph. For lifters and pushers, selection
uses factored moving mass, required stroke, operating pressure, piston speed,
and eccentric distance. For stoppers, transfer speed replaces piston speed as
the graph input. The engineer supplies the guided-load safety factor; it
multiplies mass before graph lookup and is never a catalogue assumption.

## Excluded legacy inputs

This version has no roll, pitch, or yaw offsets; mounting-style; buckling;
process-force; incline; or friction inputs. It does not derive separate
per-axis moments or apply rod-end Euler buckling.

## MGP catalogue curve evidence

The selection dataset is transcribed from the SMC `MGP Series` catalogue in
`reference/source-material/guided cylinder/MGP.md`, using the matching source
PDF vector geometry. Printed page 545 defines the case-to-graph table, the two
worked examples, the 200/400 mm/s graph choice, and the 1.7/1.0/0.6 load
coefficients through 500 mm/s. The detailed curve provenance is:

- page 546: vertical slide-bearing graphs 1–4;
- page 547: vertical ball-bushing graphs 5–8;
- page 548: vertical ball-bushing graphs 9–12;
- page 549: horizontal slide-bearing graphs 13–16;
- pages 550–551: horizontal ball-bushing graphs 17–20; and
- page 552: the two unnumbered MGPM stopper plots, recorded as graphs 21 and
  22 for bores 12–25 mm and 32–100 mm respectively.

Each source path was calibrated against its printed axis limits. Vertical and
horizontal graph coordinates were converted from their logarithmic x/y axes;
the digitizer retained every vector vertex, endpoint, bend, and labelled
segmented-axis boundary needed to reconstruct the published path. Stopper
curves retain each plateau endpoint, descending segment endpoint, and the
bore-specific terminal transfer speed. Converted values are rounded to three
significant digits. This records reproducible transcription precision, not
extra manufacturer accuracy: values closer than the plotted line thickness
must be treated as engineering approximations.

The 0.4 MPa and 0.5 MPa-or-more traces are stored separately where the source
prints two distinct curves. Where the catalogue prints one common mechanical
limit without separate pressure traces, the same geometry is tagged as
applicable to both supported pressure bands. Pressure values strictly between
0.4 and 0.5 MPa are not interpolated.

Vertical and horizontal queries use log-log interpolation only between stored
points. Stopper queries use straight-line interpolation between stored points.
No curve is extrapolated beyond its own first or last point. The selector also
keeps the catalogue limits explicit: vertical eccentric distance `L >= 200
mm` requires SMC selection software; horizontal `L > 100 mm`, piston speed
above 500 mm/s, unsupported pressure bands, non-MGPM stopper bearings, and
stopper strokes or transfer speeds outside a selected bore curve are reported
as out of envelope.

Every successful stopper-band result carries the page-552 scope cautions. The
published plots assume `L ≈ 50 mm`; a longer `L` requires selection of a bore
that is sufficiently large. If a roller conveyor applies line pressure after
the workpiece has stopped, selection must use the applicable horizontal graph
13 or 15 instead of the stopper plots. These are static manufacturer cautions,
not an additional stopper input.

As transcription anchors, graph 5 for an MGPL25/MGPA25 at 0.5 MPa or more
stores `(L, m) = (10 mm, 12.3 kg)`, `(26.2 mm, 12.3 kg)`, and `(200 mm, 1.63
kg)`. Log-log evaluation at the page-545 example's `L = 90 mm` gives about
3.62 kg, above its 3 kg load. Graph 13 for MGPM20 stores 2.47 kg at the other
page-545 example's 30 mm stroke, above its 2 kg load.

# Guided Cylinder Sizing 0.2.0 — Stage 2 Parameter Contract

## Version and compatibility

This contract is for the future `guided-cylinder-sizing@0.2.0` MGP-first
module. It is additive to the parameter registry and does not alter the
released `guided-cylinder-sizing@0.1.0` contract.

## Reused parameter IDs

| Purpose | Parameter ID |
| --- | --- |
| Moving or transferred mass | `motion.axis.total_moving_mass` |
| Required stroke | `pneumatic_guided_sizing.required_stroke` |
| Operating pressure | `pneumatic.operating_pressure` |
| Maximum piston speed | `pneumatic.max_piston_speed` |

## New parameter IDs

This version adds exactly the following IDs.

| Parameter ID | Contract |
| --- | --- |
| `pneumatic_guided_mgp_sizing.application_case` | Required enum: `vertical_lifter`, `horizontal_pusher`, or `stopper`. |
| `pneumatic_guided_mgp_sizing.eccentric_distance` | Required quantity in `mm`; minimum `0 mm`. |
| `pneumatic_guided_mgp_sizing.load_safety_factor` | Required quantity in `ratio`; minimum `1 ratio`; no default. |
| `pneumatic_guided_mgp_sizing.transfer_speed` | Required quantity in `m/s`; display units `m/s` and `m/min`. |

The existing speed dimension gains the compatible `m/min` display unit (`1 m/min = 1/60 m/s`) for `transfer_speed`.

`load_safety_factor` is an explicit engineer input. The selection workflow
multiplies the applicable moving mass by it before choosing an MGP graph.

## Removed legacy inputs

The 0.2.0 contract has no roll, pitch, yaw, mounting-style, buckling,
process-force, incline, or friction inputs. It uses no legacy moment or Euler
buckling calculation.
